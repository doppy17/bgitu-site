# bgitu-site — статичная копия публичного сайта БГИТУ

Живая версия: **https://doppy17.github.io/bgitu-site/**

Это выгрузка публичной части Django-проекта
[georgiiportnov789-dot/BGITU](https://github.com/georgiiportnov789-dot/BGITU)
(автор — Георгий Портнов; я там контрибьютер), разложенная в статические
файлы и опубликованная через GitHub Pages.

- 43 страницы: главная, университет, институты, приёмная кампания, студенту,
  расписание, новости, контакты и т. д.
- Поиск по сайту (Ctrl/⌘ + K), темы, «версия для слабовидящих» — работают, они
  целиком на клиентском JS.
- Всё лежит в подкаталоге `/bgitu-site/`, поэтому корневые ссылки в HTML
  переписаны на относительные — сайт работает и локально открытый файлом.

## Чего здесь нет

Личного кабинета, ролей, курсов, оценок и посещаемости: это серверная часть
Django с базой данных, статикой её не выложить. Вместо кабинетных страниц —
заглушки, из поискового индекса такие записи вырезаны.

## Как пересобрать

Из клона Django-проекта на `127.0.0.1:8010` (см. его README, `./run.sh`),
затем скрипт-краулер из `scripts/` этого репозитория — он обходит публичные
страницы, переписывает ссылки и складывает всё сюда. Дальше обычный
`git commit && git push` — Pages пересобирается сам (~30 секунд).
